# Truck Assembly Anatomy

แผนผังการประกอบรถดัมพ์พ่วง 3 มิติ

An interactive standalone HTML viewer published with GitHub Pages.

**Live page:** https://netzpj-max.github.io/truck-assembly-anatomy/

The supplied `truck-assembly-anatomy.html` is preserved byte-for-byte as `index.html`, including its embedded fonts and 3D code. No build step or package installation is required.

GitHub Pages serves the root of the `main` branch. Open the live page in a browser with WebGL support.
